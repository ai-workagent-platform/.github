# AI WorkAgent 플랫폼팀

생성형 AI 기반 업무 혁신을 위해 **사내 AI 플랫폼**을 구축·운영합니다.

Claude, ChatGPT, Copilot 등 다양한 AI 서비스를 도입하고, Agent · Automation · AI Governance 체계를 통해 임직원의 업무 생산성 향상을 지원합니다.

## 우리가 하는 일

| 영역 | 내용 |
|------|------|
| **AI 서비스 도입** | Claude, ChatGPT, Copilot 등 다양한 AI 서비스를 도입하고 사내 환경에 맞게 제공합니다. |
| **Agent** | 업무에 특화된 AI Agent를 구축하고 운영합니다. |
| **Automation** | 반복 업무를 자동화하여 임직원이 핵심 업무에 집중할 수 있도록 지원합니다. |
| **AI Governance** | 안전하고 책임 있는 AI 활용을 위한 거버넌스 체계를 마련합니다. |

## 목표

- 생성형 AI 기반의 업무 혁신
- 임직원의 업무 생산성 향상
- 안전하고 일관된 사내 AI 활용 환경 제공
